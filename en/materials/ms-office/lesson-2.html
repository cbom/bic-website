Lesson 2: MS Excel — Workbook, Formulas & Charts

Reading time: 15 minutes | Level: Beginner to Intermediate

What is MS Excel?

Microsoft Excel is a spreadsheet application used for data entry, calculations, data analysis, and creating charts. It organizes data in rows and columns (cells).

Key Concepts

  • Workbook: An Excel file (e.g., data.xlsx) — can contain multiple sheets
  • Worksheet: A single sheet/tab within a workbook
  • Cell: Intersection of a row and column (e.g., A1, B5, C10)
  • Cell Reference: The address of a cell (Column letter + Row number)
  • Range: A group of cells (e.g., A1:A10 means cells A1 through A10)

Data Entry & Formatting

  • Click a cell and type to enter data
  • Press Enter to move down, Tab to move right
  • Number Format: General, Number, Currency, Date, Percentage
  • Cell Formatting: Font, borders, fill colour, alignment, merge cells

Important Formulas & Functions

FunctionPurposeExample
=SUM()Add numbers=SUM(A1:A10)
=AVERAGE()Calculate average=AVERAGE(B1:B20)
=MAX()Find largest value=MAX(C1:C50)
=MIN()Find smallest value=MIN(C1:C50)
=COUNT()Count cells with numbers=COUNT(A1:A100)
=IF()Conditional logic=IF(A1>50,"Pass","Fail")
=VLOOKUP()Search and return value=VLOOKUP(A1,Sheet2!A:B,2,0)
=CONCATENATE()Join text=CONCATENATE(A1," ",B1)

Creating Charts

  1. Select the data range you want to chart
  2. Go to Insert tab → Charts group
  3. Choose chart type: Column, Bar, Line, Pie, Area
  4. Customize with Chart Tools (Design, Format)

Sorting & Filtering

  • Sort: Arrange data in ascending/descending order (Data → Sort)
  • Filter: Show only specific data that matches criteria (Data → Filter)
  • Conditional Formatting: Highlight cells based on rules (Home → Conditional Formatting)

Key Points to Remember
  • Excel organizes data in cells (rows × columns)
  • Formulas start with = sign (e.g., =SUM(A1:A10))
  • Key functions: SUM, AVERAGE, MAX, MIN, COUNT, IF
  • Charts visualize data — select data → Insert → Chart
  • Sort and Filter help manage large datasets
