Lesson 1: MS Word — Introduction & Formatting

Reading time: 15 minutes | Level: Beginner

What is MS Word?

Microsoft Word is a word processing software used for creating, editing, formatting, and printing documents. It is part of the Microsoft Office Suite and is widely used for preparing letters, reports, applications, resumes, and more.

Key Features of MS Word

  • Text Formatting: Font type, size, colour, bold, italic, underline, alignment
  • Paragraph Formatting: Spacing, indentation, alignment (left, center, right, justify)
  • Tables: Create and format tables for organized data
  • Images & Graphics: Insert pictures, shapes, WordArt, SmartArt
  • Spell Check: Automatic spelling and grammar correction
  • Mail Merge: Create personalized letters for multiple recipients
  • Headers & Footers: Add text at top/bottom of every page
  • Page Setup: Margins, orientation, paper size, page borders

MS Word Interface

  • Title Bar: Shows document name at the top
  • Ribbon: Contains tabs (Home, Insert, Design, Layout, etc.) with tool groups
  • Quick Access Toolbar: Save, Undo, Redo buttons
  • Ruler: Shows margins and indentation
  • Document Area: Main area where you type
  • Status Bar: Bottom — shows page number, word count, zoom

Creating & Saving Documents

  • New Document: Ctrl + N or File → New
  • Save: Ctrl + S (saves to current location)
  • Save As: F12 or Ctrl + Shift + S (choose location and name)
  • Open: Ctrl + O (open existing file)
  • Print: Ctrl + P (print preview and print)

Working with Tables

Insert → Table → Select rows and columns. Tables are useful for organizing information in a structured format.

Page Setup & Printing

  • Margins: Layout → Margins (Normal, Narrow, Wide, Custom)
  • Orientation: Portrait (vertical) or Landscape (horizontal)
  • Page Break: Ctrl + Enter to start a new page
  • Print Preview: Ctrl + P to see how document will print
Key Points to Remember
  • MS Word is for creating and formatting documents
  • Ribbon contains all tools organized in tabs
  • Ctrl+S = Save, Ctrl+P = Print, Ctrl+Z = Undo
  • Bold (Ctrl+B), Italic (Ctrl+I), Underline (Ctrl+U)
  • Tables: Insert → Table for structured data
