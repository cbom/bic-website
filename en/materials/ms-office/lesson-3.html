Lesson 3: MS PowerPoint — Presentations & Slides

Reading time: 12 minutes | Level: Beginner

What is MS PowerPoint?

Microsoft PowerPoint is presentation software used to create slideshows for meetings, classes, seminars, and events. It combines text, images, animations, and multimedia to deliver information visually.

Key Features

  • Slides: Individual pages of a presentation
  • Slide Layouts: Pre-designed arrangements (Title, Content, Two Column, Blank)
  • Themes & Design: Professional colour schemes and fonts
  • Animations: Add motion effects to objects
  • Transitions: Effects when moving between slides
  • Slide Show: Full-screen presentation mode
  • Speaker Notes: Notes visible only to presenter

Creating a Presentation

  1. Open PowerPoint → Choose a blank or template presentation
  2. Add title and content to the first slide
  3. Add new slides: Home → New Slide (or Ctrl+M)
  4. Choose appropriate layout for each slide
  5. Add content: text, images, shapes, charts
  6. Apply a design theme: Design → Themes
  7. Add animations and transitions
  8. Save and run the slide show (F5)

Inserting Content

  • Text: Click text placeholder and type
  • Images: Insert → Pictures (from file or online)
  • Shapes: Insert → Shapes (arrows, boxes, stars)
  • Charts: Insert → Chart (bar, pie, line graphs)
  • Videos: Insert → Video (from file or YouTube)
  • Tables: Insert → Table

Animations & Transitions

  • Animations (for objects on a slide): Entrance, Emphasis, Exit, Motion Paths
  • Transitions (between slides): Fade, Push, Wipe, Morph
  • Set timing: automatic or on click

Presenting

  • Start Show: F5 (from beginning) or Shift+F5 (from current slide)
  • Next Slide: Click, Enter, or Right Arrow
  • Previous Slide: Backspace or Left Arrow
  • End Show: Esc key
  • Laser Pointer: Ctrl + Hold Left Click

Saving & Exporting

  • Save as .pptx: Editable PowerPoint format
  • Save as .pdf: For sharing (non-editable)
  • Save as Video: Export → Create Video (.mp4)
  • Print Handouts: File → Print → Handouts (multiple slides per page)
Key Points to Remember
  • PowerPoint creates visual presentations with slides
  • New Slide: Ctrl+M | Start Show: F5 | End Show: Esc
  • Insert images, shapes, charts, and videos into slides
  • Animations = object effects; Transitions = slide-change effects
  • Can export as PDF or video for sharing
