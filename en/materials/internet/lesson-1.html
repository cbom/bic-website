Lesson 1: Internet, WWW & Web Browsers

Reading time: 12 minutes | Level: Beginner

What is the Internet?

The Internet is a global network of interconnected computers that communicate using standardized protocols (TCP/IP). It enables users to access information, communicate, and use online services.

Features of the Internet

  • Global Accessibility: Accessible from almost anywhere in the world
  • Multimedia Support: Text, images, audio, video, interactive content
  • Interactivity: Two-way communication — chats, emails, video calls
  • Dynamic Content: Websites updated in real-time

Uses of the Internet

  • Communication: Email, messaging, video conferencing (Zoom, Google Meet)
  • Information: Search engines, Wikipedia, online articles
  • Entertainment: YouTube, streaming, social media, games
  • E-Commerce: Online shopping (Amazon, Flipkart), banking
  • Education: E-learning platforms, online courses, digital libraries

World Wide Web (WWW)

The WWW is a system of interlinked hypertext documents accessed via the Internet using web browsers. It was invented by Tim Berners-Lee in 1989.

Key difference: Internet = the network infrastructure; WWW = content (websites) accessible over that network.

Web Browsers

A web browser is software that lets you view websites. Popular browsers:

  • Google Chrome — Most popular, fast, extensions support
  • Microsoft Edge — Built into Windows
  • Mozilla Firefox — Open source, privacy-focused
  • Safari — Apple's browser for Mac/iPhone

Browser Features

  • Address Bar: Type website URL (e.g., www.google.com)
  • Tabs: Open multiple websites in one window
  • Bookmarks: Save favourite websites for quick access
  • History: View previously visited websites
  • Downloads: Manage downloaded files
  • Incognito/Private Mode: Browse without saving history

Search Engines

Search engines help find information on the internet:

  • Google (google.com) — Most popular
  • Bing (bing.com) — Microsoft's search engine
  • Yahoo (yahoo.com)

Tips for better searching: Use specific keywords, put phrases in "quotes", use minus (-) to exclude words.

Key Points to Remember
  • Internet = global computer network; WWW = websites on that network
  • Web browsers (Chrome, Edge, Firefox) let you view websites
  • Search engines (Google) help find information
  • Internet used for communication, education, shopping, entertainment
