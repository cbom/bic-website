Lesson 3: Input/Output Devices, CPU & Memory

Reading time: 15 minutes | Level: Beginner

Input Devices

Input devices are used to send data and instructions to the computer.

  • Keyboard: Primary text input device with letter, number, function, and special keys
  • Mouse: Pointing device for clicking, selecting, dragging — left button, right button, scroll wheel
  • Scanner: Converts physical documents/images into digital format
  • Microphone: Captures audio/voice input
  • Webcam: Captures video input for conferencing or recording
  • Joystick: Used for gaming and navigation
  • Touchscreen: Combined input/output — tap to interact directly

Output Devices

Output devices present processed data in human-readable form.

  • Monitor: Displays text, images, videos, and software interface
  • Printer: Produces hard copy of documents or images on paper
  • Speakers: Produce sound output from audio files or notifications
  • Projector: Enlarges and displays visual output on screen or wall
  • Headphones: Personal audio output device

Central Processing Unit (CPU)

The CPU is the "brain" of the computer. It performs all processing tasks and controls other components.

  • Control Unit (CU): Directs the flow of data and instructions within the system
  • Arithmetic Logic Unit (ALU): Performs arithmetic calculations (+, -, ×, ÷) and logical comparisons (AND, OR, NOT)
  • Registers: Temporary memory units inside the CPU for quick data access during processing

Memory and Storage

Primary Memory

  • RAM (Random Access Memory): Volatile (temporary) memory — stores data while programs are running. Data lost when power off.
  • ROM (Read Only Memory): Non-volatile — contains essential startup instructions (BIOS). Cannot be easily modified.

Secondary Memory (Storage)

  • HDD (Hard Disk Drive): Traditional storage with large capacity, mechanical parts
  • SSD (Solid State Drive): Faster, more durable, no moving parts
  • USB Flash Drive: Portable storage for data transfer
  • CD/DVD: Optical storage media
  • Memory Cards: Used in cameras, phones for extra storage

Other Important Components

  • Motherboard: Main circuit board connecting all components — houses CPU, memory slots, ports
  • Power Supply Unit (PSU): Converts electrical power for internal components
  • Graphics Card (GPU): Handles image/video rendering

Software vs Hardware

HardwareSoftware
Physical parts you can touchPrograms/instructions you can only see on screen
Keyboard, Mouse, Monitor, CPUWindows, MS Word, Chrome, Games
Wears out over timeCan be updated or reinstalled
Key Points to Remember
  • Input devices send data TO the computer; Output devices show results FROM the computer
  • CPU = Control Unit + ALU + Registers
  • RAM = temporary (volatile); ROM = permanent (non-volatile)
  • HDD/SSD = secondary storage for permanent data
  • Hardware = physical; Software = programs
