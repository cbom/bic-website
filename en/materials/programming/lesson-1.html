Lesson 1: Introduction to Programming & C Language

Reading time: 15 minutes | Level: Intermediate

What is Programming?

Programming is the process of writing instructions that a computer can understand and execute to perform a specific task. These instructions are written using a programming language.

Basic Concepts

  • Algorithm: A step-by-step solution to a problem
  • Flowchart: A graphical representation of the logic using shapes
  • Source Code: Instructions written in a programming language
  • Compiler: Software that translates source code into machine language
  • Execution: Running the compiled program

C Programming Language

C was developed by Dennis Ritchie in 1972. It is called the "mother of all languages" because many modern languages (C++, Java, Python) are influenced by it.

Structure of a C Program

#include <stdio.h>    // Header file for input/output

int main() {           // Main function - program starts here
    printf("Hello World!\n");   // Print text on screen
    return 0;          // Program ended successfully
}

Variables and Data Types

Data TypeUsed ForExample
intWhole numbersint age = 25;
floatDecimal numbersfloat price = 99.5;
charSingle characterchar grade = 'A';
doubleLarge decimal numbersdouble pi = 3.14159;

Operators

  • Arithmetic: + (add), - (subtract), * (multiply), / (divide), % (remainder)
  • Relational: == (equal), != (not equal), > (greater), < (less), >= , <=
  • Logical: && (AND), || (OR), ! (NOT)

Decision Making (if-else)

if (marks >= 50) {
    printf("Pass");
} else {
    printf("Fail");
}

Loops

// Print numbers 1 to 10
for (int i = 1; i <= 10; i++) {
    printf("%d\n", i);
}

// While loop
int count = 1;
while (count <= 5) {
    printf("%d\n", count);
    count++;
}

Functions

int add(int a, int b) {
    return a + b;
}

int main() {
    int result = add(5, 3);  // result = 8
    printf("Sum = %d", result);
    return 0;
}
Key Points to Remember
  • Programming = writing instructions for computers
  • C program: #include, main(), printf(), return 0
  • Data types: int, float, char, double
  • Control flow: if-else for decisions, for/while for loops
  • Functions break code into reusable pieces
