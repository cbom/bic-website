Lesson 2: Python Programming Basics

Reading time: 15 minutes | Level: Intermediate

What is Python?

Python is a high-level, easy-to-learn programming language known for its simple and readable syntax. Created by Guido van Rossum in 1991, it is widely used in web development, data science, AI, automation, and education.

Why Python?

  • Simple and readable syntax (close to English)
  • Free and open-source
  • Large library of pre-built tools
  • Used everywhere: web, AI, data science, games, automation
  • Great for beginners

Getting Started

Install Python from python.org or use an IDE like IDLE (comes with Python), VS Code, or PyCharm.

Your First Program

print("Hello, World!")
print("Welcome to Python")

Variables and Data Types

name = "Rahul"        # String (text)
age = 20              # Integer (whole number)
height = 5.8          # Float (decimal)
is_student = True     # Boolean (True/False)

print(name)
print("Age:", age)

Python automatically detects the data type — no need to declare like C.

Operators

# Arithmetic
print(10 + 3)    # 13
print(10 - 3)    # 7
print(10 * 3)    # 30
print(10 / 3)    # 3.333...
print(10 // 3)   # 3 (integer division)
print(10 % 3)    # 1 (remainder)
print(2 ** 3)    # 8 (power)

Decision Making

marks = 75

if marks >= 80:
    print("Grade A")
elif marks >= 60:
    print("Grade B")
elif marks >= 40:
    print("Grade C")
else:
    print("Fail")

Note: Python uses indentation (spaces) instead of curly braces {} to define blocks.

Loops

# For loop - print 1 to 5
for i in range(1, 6):
    print(i)

# While loop
count = 1
while count <= 5:
    print(count)
    count += 1

# Loop through a list
fruits = ["Apple", "Banana", "Mango"]
for fruit in fruits:
    print(fruit)

Functions

def greet(name):
    print("Hello, " + name + "!")

def add(a, b):
    return a + b

greet("Rahul")         # Hello, Rahul!
result = add(5, 3)     # result = 8
print("Sum:", result)

Lists

numbers = [10, 20, 30, 40, 50]
print(numbers[0])      # 10 (first item)
print(numbers[-1])     # 50 (last item)
numbers.append(60)     # Add item
print(len(numbers))    # 6 (length)

Input from User

name = input("Enter your name: ")
age = int(input("Enter your age: "))
print("Hello", name, "! You are", age, "years old.")
Key Points to Remember
  • Python is simple, readable, and powerful
  • No data type declaration needed — Python auto-detects
  • Indentation is mandatory (defines code blocks)
  • if/elif/else for decisions; for/while for loops
  • def creates functions; lists store collections of items
