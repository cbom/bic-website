Lesson 1: Introduction to Operating System

Reading time: 12 minutes | Level: Beginner

What is an Operating System?

An Operating System (OS) is the fundamental software that acts as an intermediary between the computer hardware and the user. It manages computer hardware resources and provides essential services for computer programs.

Without an operating system, a computer would be useless because the user would have no way to interact with the hardware.

Key Functions of an OS

  • Resource Management: Manages CPU, memory, disk drives, and printers. When you open a program, the OS allocates memory and CPU time to it.
  • File Management: Organizes and controls data storage. Allows creating, deleting, copying, and moving files.
  • User Interface: Provides GUI (Graphical User Interface) or CLI (Command Line Interface) for user interaction.
  • Task Management: Controls program execution and allows multitasking — multiple programs running simultaneously.
  • Security: Protects data through user accounts, passwords, and access permissions.

Popular Operating Systems

  • Microsoft Windows: Most widely used desktop OS, known for user-friendly GUI
  • macOS: Apple's operating system for Mac computers
  • Linux: Free, open-source OS used in servers and by developers
  • Android: Google's mobile OS for smartphones
  • iOS: Apple's mobile OS for iPhone and iPad

Booting Process

Booting is the process of starting a computer and loading the operating system into memory.

  1. Power On → POST (Power-On Self Test) checks hardware
  2. BIOS/UEFI loads from ROM
  3. Boot loader finds and loads the Operating System
  4. OS loads into RAM and desktop/login screen appears

Cold Boot: Starting from power-off state | Warm Boot: Restarting (Ctrl+Alt+Del)

Key Points to Remember
  • OS is the bridge between user and hardware
  • Main functions: Resource, File, Task, and Security Management
  • Windows is the most common desktop OS
  • Booting = process of loading OS into memory
