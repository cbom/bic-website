Lesson 2: Windows Desktop & File Management

Reading time: 15 minutes | Level: Beginner

Windows Desktop

The Desktop is the main screen you see after Windows starts. It contains:

  • Icons: Small pictures representing files, folders, or programs (e.g., This PC, Recycle Bin)
  • Taskbar: Bar at the bottom — shows Start button, pinned apps, system tray, clock
  • Start Menu: Click the Windows icon — access all programs, settings, power options
  • Wallpaper: Background image on the desktop
  • System Tray: Right side of taskbar — shows notifications, WiFi, volume, battery

File and Folder Management

What are Files and Folders?

  • File: A document, image, video, or program stored on the computer (e.g., letter.docx, photo.jpg)
  • Folder: A container that organizes files (like a physical folder in a cabinet)

Windows Explorer (File Explorer)

File Explorer is the tool to browse, manage, and organize files and folders. Open it by pressing Win + E.

Control Panel & Settings

Control Panel/Settings lets you configure your computer:

  • Personalization: Change wallpaper, themes, colours, lock screen
  • Date & Time: Set correct date, time, and timezone
  • User Accounts: Create/manage user accounts and passwords
  • Programs: Install or uninstall software
  • Network: WiFi and internet connection settings
  • Display: Screen resolution, brightness

System Tools

  • Task Manager (Ctrl+Shift+Esc): View running programs, end unresponsive apps
  • Disk Cleanup: Remove temporary files to free space
  • Defragment: Optimize hard drive performance
  • Calculator: Built-in calculator app
  • Snipping Tool: Take screenshots

Shut Down Options

  • Shut Down: Completely turns off the computer
  • Restart: Turns off and on again (useful after updates)
  • Sleep: Low-power state, quick resume
  • Log Off: Closes your session, others can log in
Key Points to Remember
  • Desktop has icons, taskbar, start menu, and system tray
  • File Explorer (Win+E) manages files and folders
  • Copy = Ctrl+C, Paste = Ctrl+V, Cut = Ctrl+X
  • Control Panel/Settings for system configuration
  • Task Manager (Ctrl+Shift+Esc) to manage running programs
