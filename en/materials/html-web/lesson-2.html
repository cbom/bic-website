Lesson 2: CSS Styling & Responsive Design

Reading time: 15 minutes | Level: Intermediate

What is CSS?

CSS (Cascading Style Sheets) is used to style and format HTML elements — controlling colours, fonts, spacing, layout, and more.

Ways to Add CSS

  • Inline: style attribute on element: <p style="color:red;">
  • Internal: <style> tag in <head>
  • External: Separate .css file linked with <link> tag (recommended)
<!-- External CSS -->
<link rel="stylesheet" href="style.css">

CSS Selectors

/* Element selector */
h1 { color: blue; }

/* Class selector */
.highlight { background: yellow; }

/* ID selector */
#header { font-size: 24px; }

/* Multiple selectors */
h1, h2, h3 { font-family: Arial; }

Box Model

Every HTML element is a box with: Content → Padding → Border → Margin

.box {
    width: 300px;
    padding: 20px;      /* space inside */
    border: 2px solid blue;
    margin: 10px;       /* space outside */
}

Flexbox Layout

Flexbox makes it easy to arrange elements in a row or column.

.container {
    display: flex;
    justify-content: space-between;  /* horizontal spacing */
    align-items: center;             /* vertical alignment */
}

.item {
    flex: 1;  /* equal width items */
}

Responsive Design (Media Queries)

Makes websites look good on all screen sizes (phone, tablet, desktop).

/* Default: Desktop */
.container { display: flex; }

/* Tablet: screens below 768px */
@media (max-width: 768px) {
    .container { flex-direction: column; }
}

/* Mobile: screens below 480px */
@media (max-width: 480px) {
    body { font-size: 14px; }
}

Basic JavaScript Introduction

JavaScript adds interactivity to web pages (clicks, animations, validation).

<script>
// Show alert on button click
function showMessage() {
    alert("Hello! Welcome to our website.");
}

// Change text content
document.getElementById("demo").innerHTML = "Changed!";
</script>

<button onclick="showMessage()">Click Me</button>
<p id="demo">Original text</p>
Key Points to Remember
  • CSS styles HTML elements (colours, fonts, layout)
  • External CSS (separate file) is best practice
  • Selectors: element, .class, #id
  • Box Model: content + padding + border + margin
  • Flexbox for layout; Media queries for responsive design
  • JavaScript adds interactivity
