Lesson 2: Notepad & WordPad Basics

Reading time: 12 minutes | Level: Beginner

Notepad

What is Notepad?

Notepad is a simple text editor that comes with Windows. It is used for writing plain text without any formatting (no bold, no colours, no images).

How to Open

  • Start → Search "Notepad" → Click Notepad
  • Or: Win+R → type notepad → Enter

Notepad Menu Bar

  • File: New, Open, Save, Save As, Print
  • Edit: Undo, Cut, Copy, Paste, Find, Replace, Select All
  • Format: Word Wrap, Font (change font type and size)
  • View: Status Bar, Zoom

Key Features

  • Word Wrap: Format → Word Wrap (text wraps to fit window)
  • Find: Ctrl + F (search for text)
  • Replace: Ctrl + H (find and replace text)
  • Font Change: Format → Font (change type and size)
  • Saves as .txt (plain text file)

Uses of Notepad

  • Quick notes and to-do lists
  • Writing HTML code
  • Editing configuration files
  • Removing formatting from copied text

WordPad

What is WordPad?

WordPad is a basic word processor — more powerful than Notepad but simpler than MS Word. It supports text formatting, images, and basic document creation.

How to Open

  • Start → Search "WordPad" → Click WordPad
  • Or: Win+R → type wordpad → Enter

WordPad Features

  • Text Formatting: Bold, Italic, Underline, Font size, Colour
  • Paragraph: Alignment (Left, Center, Right), Bullet points, Line spacing
  • Insert: Pictures, Date/Time, Drawing
  • Ruler: Set margins and indentation
  • Saves as .rtf (Rich Text Format) or .docx

Comparison: Notepad vs WordPad vs MS Word

Practice Activities

  1. Notepad: Type a short paragraph about your favourite hobby. Save it as "myhobby.txt"
  2. WordPad: Write a leave application with proper formatting — bold heading, date, body text, signature
Key Points to Remember
  • Notepad = plain text editor (.txt), no formatting
  • WordPad = basic word processor (.rtf), basic formatting
  • Notepad for quick notes and code; WordPad for simple documents
  • MS Word for professional documents with full features
