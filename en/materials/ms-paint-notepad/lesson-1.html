Lesson 1: MS Paint — Drawing & Tools

Reading time: 12 minutes | Level: Beginner

What is MS Paint?

MS Paint is a basic graphics and painting program that comes pre-installed with Windows. It allows users to create simple drawings, edit pictures, and save them in formats like JPEG, PNG, BMP, and GIF.

How to Open MS Paint

  • Start Menu → Search "Paint" → Click Paint
  • Or: Start → Windows Accessories → Paint
  • Or: Press Win+R, type mspaint, press Enter

MS Paint Interface

  • Title Bar: Shows file name
  • Ribbon/Toolbar: Contains all tools and options
  • Drawing Area (Canvas): White area where you draw
  • Colour Palette: Choose colours for drawing
  • Status Bar: Shows cursor position and canvas size

Main Tools

ToolUse
PencilFree-hand thin line drawing
BrushThicker drawing with various brush styles
EraserRemove parts of the drawing
Fill with ColourFill enclosed area with selected colour
Text Tool (A)Add text to the drawing
Colour PickerPick a colour from the canvas
Magnifier/ZoomZoom in/out of the canvas
ShapesDraw rectangle, circle, line, polygon, etc.
SelectSelect area to move, copy, or delete

Creating and Saving

  • New File: Ctrl + N
  • Save: Ctrl + S (choose format: PNG, JPEG, BMP, GIF)
  • Save As: F12 (save with new name)
  • Open: Ctrl + O
  • Print: Ctrl + P

Useful Operations

  • Resize: Home → Resize → Change by percentage or pixels
  • Rotate: Home → Rotate → Rotate 90°/180°/Flip
  • Crop: Select area → Crop button
  • Undo: Ctrl + Z | Redo: Ctrl + Y

Practice Activity

Try creating these in MS Paint:

  1. A scenery with mountains, sun, trees, and river
  2. Indian National Flag with correct colours
  3. A birthday greeting card with text and shapes
  4. Your name written using different colours and fonts
Key Points to Remember
  • MS Paint is for basic drawing and image editing
  • Tools: Pencil, Brush, Eraser, Fill, Text, Shapes
  • Save formats: PNG (best quality), JPEG (photos), BMP (uncompressed)
  • Ctrl+Z = Undo, Ctrl+S = Save, Ctrl+N = New
