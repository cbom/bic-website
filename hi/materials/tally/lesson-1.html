पाठ 1: टैली प्राइम का परिचय और कंपनी बनाना

पढ़ने का समय: 15 मिनट | स्तर: शुरुआती

टैली प्राइम क्या है?

टैली प्राइम एक व्यापक अकाउंटिंग सॉफ्टवेयर है जो व्यवसायों में वित्तीय लेनदेन प्रबंधित करता है। यह अकाउंटिंग को स्वचालित करता है, त्रुटियाँ कम करता है।

टैली प्राइम इंटरफ़ेस

  • Gateway of Tally: मुख्य स्क्रीन
  • मेनू बार: Company, Data, Exchange, Go To
  • बटन बार: दाईं ओर क्विक एक्सेस बटन

कंपनी बनाना

  1. टैली प्राइम खोलें
  2. Gateway → Create Company (Alt+F3 → Create)
  3. विवरण भरें: कंपनी का नाम, पता, राज्य, वित्तीय वर्ष
  4. Ctrl + A से Accept करें

लेजर और ग्रुप

लेजर: लेनदेन रिकॉर्ड करने के लिए अकाउंट हेड (जैसे कैश, बैंक, सेल्स)

ग्रुप: लेजर को व्यवस्थित करने वाली श्रेणियाँ

लेजर बनाना

  1. Gateway → Create → Ledger
  2. नाम दर्ज करें (जैसे "HDFC Bank")
  3. ग्रुप चुनें (जैसे "Bank Accounts")
  4. Ctrl + A से Accept
