पाठ 1: प्रोग्रामिंग का परिचय और C भाषा

पढ़ने का समय: 15 मिनट | स्तर: मध्यम

प्रोग्रामिंग क्या है?

प्रोग्रामिंग निर्देश लिखने की प्रक्रिया है जिन्हें कंप्यूटर समझ और निष्पादित कर सकता है। ये निर्देश प्रोग्रामिंग भाषा में लिखे जाते हैं।

मूल अवधारणाएँ

  • एल्गोरिदम: समस्या का चरण-दर-चरण समाधान
  • फ़्लोचार्ट: लॉजिक का ग्राफिकल प्रतिनिधित्व
  • सोर्स कोड: प्रोग्रामिंग भाषा में लिखे निर्देश
  • कंपाइलर: सोर्स कोड को मशीन भाषा में बदलता है

C प्रोग्रामिंग

C Dennis Ritchie द्वारा 1972 में बनाई गई। इसे "सभी भाषाओं की माँ" कहते हैं।

C प्रोग्राम की संरचना

#include <stdio.h>    // हेडर फ़ाइल

int main() {           // मुख्य फंक्शन
    printf("Hello World!\n");   // स्क्रीन पर प्रिंट
    return 0;          // सफलतापूर्वक समाप्त
}

डेटा टाइप

डेटा टाइपउपयोगउदाहरण
intपूर्ण संख्याint age = 25;
floatदशमलव संख्याfloat price = 99.5;
charएक अक्षरchar grade = 'A';

निर्णय (if-else)

if (marks >= 50) {
    printf("Pass");
} else {
    printf("Fail");
}

लूप

// 1 से 10 प्रिंट
for (int i = 1; i <= 10; i++) {
    printf("%d\n", i);
}
मुख्य बिंदु
  • प्रोग्रामिंग = कंप्यूटर के लिए निर्देश लिखना
  • C प्रोग्राम: #include, main(), printf(), return 0
  • डेटा टाइप: int, float, char
  • if-else निर्णय के लिए, for/while लूप के लिए
