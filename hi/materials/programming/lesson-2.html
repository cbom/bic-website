पाठ 2: Python प्रोग्रामिंग की मूल बातें

पढ़ने का समय: 15 मिनट | स्तर: मध्यम

Python क्या है?

Python सरल और पढ़ने में आसान प्रोग्रामिंग भाषा है। Guido van Rossum ने 1991 में बनाई। वेब डेवलपमेंट, डेटा साइंस, AI में व्यापक उपयोग।

Python क्यों?

  • सरल सिंटैक्स (अंग्रेजी जैसा)
  • मुफ्त और ओपन-सोर्स
  • विशाल लाइब्रेरी
  • शुरुआती के लिए बढ़िया

पहला प्रोग्राम

print("Hello, World!")
print("Python में आपका स्वागत है")

वेरिएबल और डेटा टाइप

name = "राहुल"       # String (टेक्स्ट)
age = 20             # Integer (पूर्ण संख्या)
height = 5.8         # Float (दशमलव)
is_student = True    # Boolean (True/False)

print(name)
print("उम्र:", age)

निर्णय

marks = 75

if marks >= 80:
    print("Grade A")
elif marks >= 60:
    print("Grade B")
elif marks >= 40:
    print("Grade C")
else:
    print("Fail")

लूप

# 1 से 5 प्रिंट
for i in range(1, 6):
    print(i)

# लिस्ट में लूप
fruits = ["सेब", "केला", "आम"]
for fruit in fruits:
    print(fruit)

फंक्शन

def greet(name):
    print("नमस्ते, " + name + "!")

def add(a, b):
    return a + b

greet("राहुल")
result = add(5, 3)
print("योग:", result)

यूज़र इनपुट

name = input("अपना नाम दर्ज करें: ")
age = int(input("अपनी उम्र दर्ज करें: "))
print("नमस्ते", name, "! आपकी उम्र", age, "है।")
मुख्य बिंदु
  • Python सरल, पठनीय और शक्तिशाली है
  • डेटा टाइप घोषणा की ज़रूरत नहीं
  • इंडेंटेशन अनिवार्य है (कोड ब्लॉक परिभाषित करता है)
  • if/elif/else निर्णय; for/while लूप
  • def फंक्शन बनाता है; लिस्ट डेटा संग्रहित करती है
