पाठ 2: Windows डेस्कटॉप और फाइल मैनेजमेंट

पढ़ने का समय: 15 मिनट | स्तर: शुरुआती

Windows डेस्कटॉप

  • आइकन: फ़ाइल, फ़ोल्डर या प्रोग्राम का प्रतिनिधित्व करने वाली छोटी तस्वीरें
  • टास्कबार: नीचे की बार — Start बटन, पिन किए गए ऐप्स, सिस्टम ट्रे, घड़ी
  • स्टार्ट मेनू: Windows आइकन पर क्लिक — सभी प्रोग्राम, सेटिंग्स
  • वॉलपेपर: डेस्कटॉप पर पृष्ठभूमि छवि
  • सिस्टम ट्रे: दाईं ओर — WiFi, वॉल्यूम, बैटरी

फाइल और फ़ोल्डर

  • फाइल: दस्तावेज़, इमेज, वीडियो या प्रोग्राम (जैसे letter.docx, photo.jpg)
  • फ़ोल्डर: फ़ाइलों को व्यवस्थित करने वाला कंटेनर

कंट्रोल पैनल / सेटिंग्स

  • पर्सनलाइज़ेशन: वॉलपेपर, थीम, रंग बदलें
  • दिनांक और समय: सही तारीख, समय सेट करें
  • प्रोग्राम: सॉफ्टवेयर इंस्टॉल या अनइंस्टॉल करें
  • नेटवर्क: WiFi और इंटरनेट सेटिंग्स

सिस्टम टूल्स

  • टास्क मैनेजर (Ctrl+Shift+Esc): चल रहे प्रोग्राम देखें, बंद करें
  • डिस्क क्लीनअप: अस्थायी फ़ाइलें हटाकर जगह खाली करें
  • स्निपिंग टूल: स्क्रीनशॉट लें
मुख्य बिंदु
  • डेस्कटॉप: आइकन, टास्कबार, स्टार्ट मेनू, सिस्टम ट्रे
  • फाइल एक्सप्लोरर (Win+E) फ़ाइलें प्रबंधित करता है
  • कॉपी = Ctrl+C, पेस्ट = Ctrl+V, कट = Ctrl+X
  • टास्क मैनेजर (Ctrl+Shift+Esc) प्रोग्राम प्रबंधित करता है
