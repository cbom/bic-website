पाठ 1: HTML5 टैग, एट्रिब्यूट और फ़ॉर्म

पढ़ने का समय: 15 मिनट | स्तर: मध्यम

HTML क्या है?

HTML (HyperText Markup Language) वेब पेज बनाने की मानक भाषा है। HTML5 नवीनतम संस्करण है। टैग HTML के बिल्डिंग ब्लॉक हैं।

बेसिक HTML संरचना

<!DOCTYPE html>
<html>
<head>
    <title>मेरा पहला वेब पेज</title>
</head>
<body>
    <h1>मेरी वेबसाइट में आपका स्वागत है</h1>
    <p>यह एक पैराग्राफ है।</p>
</body>
</html>

सामान्य HTML टैग

टैगउद्देश्यउदाहरण
<h1> - <h6>शीर्षक (बड़े से छोटे)<h1>मुख्य शीर्षक</h1>
<p>पैराग्राफ<p>कुछ टेक्स्ट</p>
<a>लिंक<a href="url">क्लिक</a>
<img>इमेज<img src="photo.jpg">
<ul>, <ol>, <li>सूचियाँ<ul><li>आइटम</li></ul>
<table>तालिका<table><tr><td>डेटा</td></tr></table>

HTML फ़ॉर्म

<form action="submit.html" method="POST">
    <label>नाम:</label>
    <input type="text" name="name" required>

    <label>ईमेल:</label>
    <input type="email" name="email">

    <label>पासवर्ड:</label>
    <input type="password" name="pass">

    <button type="submit">जमा करें</button>
</form>

इनपुट प्रकार

  • text — एक लाइन टेक्स्ट
  • email — ईमेल वैलिडेशन के साथ
  • password — छिपा हुआ टेक्स्ट
  • number — संख्या
  • radio — एक चयन
  • checkbox — एकाधिक चयन
  • date — तारीख
मुख्य बिंदु
  • HTML टैग से वेब पेज संरचना बनाता है
  • संरचना: <html> → <head> + <body>
  • सामान्य: h1-h6, p, a, img, ul/ol, div, table
  • फ़ॉर्म: <form>, <input>, <textarea>, <button>
