पाठ 2: CSS स्टाइलिंग और रेस्पॉन्सिव डिज़ाइन

पढ़ने का समय: 15 मिनट | स्तर: मध्यम

CSS क्या है?

CSS (Cascading Style Sheets) HTML तत्वों को स्टाइल और फ़ॉर्मेट करता है — रंग, फ़ॉन्ट, स्पेसिंग, लेआउट।

CSS जोड़ने के तरीके

  • Inline: तत्व पर style: <p style="color:red;">
  • Internal: <style> टैग <head> में
  • External: अलग .css फ़ाइल (सबसे अच्छा तरीका)

CSS सेलेक्टर

/* एलिमेंट सेलेक्टर */
h1 { color: blue; }

/* क्लास सेलेक्टर */
.highlight { background: yellow; }

/* ID सेलेक्टर */
#header { font-size: 24px; }

सामान्य CSS प्रॉपर्टीज

प्रॉपर्टीउद्देश्यउदाहरण
colorटेक्स्ट रंगcolor: #333;
background-colorपृष्ठभूमि रंगbackground-color: #f0f0f0;
font-sizeटेक्स्ट आकारfont-size: 16px;
marginबाहर की जगहmargin: 10px;
paddingअंदर की जगहpadding: 15px;
borderबॉर्डरborder: 1px solid #000;

बॉक्स मॉडल

हर HTML एलिमेंट एक बॉक्स है: Content → Padding → Border → Margin

Flexbox लेआउट

.container {
    display: flex;
    justify-content: space-between;
    align-items: center;
}

रेस्पॉन्सिव डिज़ाइन (Media Queries)

सभी स्क्रीन आकारों (फोन, टैबलेट, डेस्कटॉप) पर अच्छा दिखने के लिए।

/* डेस्कटॉप डिफ़ॉल्ट */
.container { display: flex; }

/* टैबलेट: 768px से नीचे */
@media (max-width: 768px) {
    .container { flex-direction: column; }
}

/* मोबाइल: 480px से नीचे */
@media (max-width: 480px) {
    body { font-size: 14px; }
}

JavaScript का परिचय

<script>
function showMessage() {
    alert("नमस्ते! स्वागत है।");
}
</script>

<button onclick="showMessage()">क्लिक करें</button>
मुख्य बिंदु
  • CSS HTML तत्वों को स्टाइल करता है
  • External CSS (अलग फ़ाइल) सबसे अच्छा
  • सेलेक्टर: element, .class, #id
  • Box Model: content + padding + border + margin
  • Flexbox लेआउट के लिए; Media queries रेस्पॉन्सिव के लिए
